# 使用指南

## 第一次打开

全新安装没有预装内容：
- **手机与平板端**：首页欢迎卡片直接提供原生网址输入框与「📋 一键读取手机剪贴板并导入」按钮；复制自行合法获取的配置链接或 JSON 后点击即可一键导入，也可点击「📂 选择手机本地 JSON 配置文件」，**无需扫码**。
- **电视与盒子端**：选择“导入我的配置”，手机连接同一局域网后扫码，在手机页面粘贴自行合法获取的配置地址并提交；也可选“遥控输入”填写地址或选择本地文件。

地址输入框默认为空；使用过的地址会保存在本机，便于之后更新。导入成功只代表配置可读取，不代表其中每个项目都能播放。

本项目不提供影视资源及配置地址。不要将未知来源的账号凭据或不可信扩展导入设备。

## 首页和遥控操作

方向键移动焦点，确认键打开项目，返回键关闭当前页面或弹窗。首页顶部左侧展示最近一部的继续播放卡片，右侧展示最多三张更早的历史卡片，下方为分类切换与默认五列的 2:3 海报片库；分类来自用户配置，标题完整展示；整行放不下时按钮换行，超长标题在按钮内换行。遥控上下按实际分类行移动。较多的分类放在“更多分类”面板。支持分页的分类底部可加载更多。点击紧邻“发现”标题右侧的描边来源按钮切换片源，其名称不会随海报焦点变化。进入详情再返回，会恢复当前分类、已加载内容和焦点。

右侧悬浮图标 Dock 只在首页显示；搜索、收藏、直播、设置、历史及其他二级页面隐藏导航，通过返回键逐级回退。

每排最右侧海报继续按右进入 Dock，上下键切换首页、搜索、直播、收藏、网盘与设置；按左回到原卡片。聚焦时以带小指向角的圆角气泡显示图标名称，当前页面由小圆点标记。Dock 固定在屏幕右侧，不随片库滚动。

首页按返回直接退出应用，不再弹出退出确认框。

## 继续观看

播放后，首页会显示“继续观看”。记录保留在本机，最多 60 部；点击继续观看卡片先进入介绍选集页，再手动选择继续播放，恢复对应集数和进度。接近片尾的记录再次打开会从头播放。若原来的来源、线路或集数已经变更，会提示重新选择。

“观看历史”页面可移除单条记录或清空记录；也可从设置的“搜索与数据”进入。覆盖升级保留本机记录，配置备份不包含观看历史。

## 全局搜索和输入

右侧“搜索”图标是独立页面。输入停顿约 0.65 秒后自动检索，无须点击搜索；“立即搜索”可提前发起。继续输入会取消上一轮并忽略过期结果。内置键盘由遥控器操作，不依赖系统输入法。可以选择中文候选字，也可输入完整拼音或首拼；最终匹配受本地字词典、已学习标题和配置接口能力影响。结果按配置项返回，部分请求失败不会被当作“找到结果”。在设置中可调整检索并发数和等待时间。

## 内容详情

进入影片详情后，左侧展示大幅竖版封面，边缘渐隐至柔化背景；右侧显示名称、简介、开始/继续播放和收藏，下方显示线路与选集；不显示首页侧边导航。详情未提供封面时沿用列表封面，无图片时显示占位。用遥控器返回键或左上“返回”回到上一页。

## 播放与字幕

从内容详情选择线路与集数。全屏观看时，单击遥控器确认键直接暂停／继续；上下键同步显示顶部片名与集数、独立进度条和底部紧凑 Dock，焦点先落在进度条。片名下方显示当前视频轨的实际分辨率；无法读取时显示未知，不使用标题里的清晰度标签推断。屏幕中央显示播放／暂停操作图形；播放时显示暂停图形，暂停时显示继续播放图形。在进度条上左右键跳转、确认键暂停／继续，向下进入工具按钮。焦点在工具按钮时，确认执行相应操作。工具条显示时按返回先隐藏工具条；工具条隐藏时再按返回，缩成小屏并回到介绍选集页，保留左侧大海报，右侧小屏继续播放并保留原暂停状态；焦点在小屏时按确认恢复全屏。在介绍选集页可切换剧集；再次返回离开此页并停止播放。弹窗打开时，返回先关闭弹窗。

Dock 提供选集、线路、下集、倍速、画面、字幕、更多；播放器、解码、音轨、刷新、重播、上一集、片头片尾、弹幕、音效、色彩、循环及播放信息收在“更多”。单集电影或最后一集的“下集”按钮仍可聚焦、点击；没有后续剧集时会显示“无下集”气泡，按确认或返回关闭后回到原按钮，播放继续。Dock 内没有单独的暂停按钮。“更多”以及播放子菜单从所选按钮上方展开为圆角气泡；上下滚动选择，返回关闭并恢复原按钮焦点。某些菜单只在播放器与内容实际支持时有效。无法解码时可尝试切换播放内核或解码模式，不能保证每种设备/文件组合都有效。

外挂字幕通过系统文件选择器导入；支持范围取决于当前播放内核。弹幕可加载兼容数据，项目本身不提供弹幕服务。音效处理受设备音频会话支持限制，色彩档位不是 HDR 或专有画质技术的替代品。

配置与壁纸地址输入使用应用内置遥控键盘，支持字母、数字、网址符号和大小写切换，不自动调用系统输入法。

## 设置

| 页面 | 操作 |
| --- | --- |
| 首页与壁纸 | 海报列数、壁纸、压暗与减少动态效果 |
| 播放与字幕 | 播放器、解码、比例、缓冲、速度、循环、自动下一集、跳过时长、字幕和音画选项 |
| 搜索与数据 | 搜索并发与等待、导入配置、启用扩展、备份还原和清理 |

右侧“网盘”图标打开向左展开的账号面板，包含统一登录入口、凭据管理和网盘顺序；设置页不再重复放置账号入口。面板只是调用兼容扩展的入口；未导入支持相应能力的配置时不能登录。账号状态应以服务提供方或扩展的实际提示为准，出现二维码不等于已经登录。

壁纸支持本地图片或图片地址。电视没有系统文件选择器时，本地导入、字幕及备份文件操作可能不可用。图片地址会连接到用户指定的服务器。

## 备份和升级

备份包含配置原文及白名单内的播放/外观偏好，不包含扩展另行保存的登录状态。**配置原文中的令牌、账号或其他敏感字段也会被备份**；不要把备份上传到公开 Issue 或仓库。还原会在确认后替换对应配置和偏好。

覆盖安装应使用相同签名。自行构建的开发签名可能与项目发布包不同；升级前请自行备份必要数据，不能保证通过卸载再安装保留登录状态。

## 常见问题

- **首页没有内容？** 全新安装为空是预期行为。先导入自己的配置；网络失败、空列表和接口变更也会导致无法加载。
- **拼音结果不准确？** 首拼可能有多个含义，试用完整中文或全拼。结果仍依赖用户导入的配置。
- **播放失败？** 检查内容是否仍可访问、是否需要本人登录、设备是否支持其编码；再尝试切换内核。
- **某个设置没有效果？** 部分功能由系统或扩展提供，不能跨设备强制实现。
- **在哪里获取影视资源？** 本项目不提供资源、订阅地址、获取渠道或账号。请自行合法获取。

## 解码组件与排错

从 0.3.3 起，安装包内置音频和 AV1 / VP9 软解码扩展，无需另装组件。优先保留自动解码；在设置中打开“解码组件”检查加载状态，在播放菜单的“播放信息”查看实际使用的解码器。系统播放器不使用这些扩展。网络、账号和临时地址失效不能靠安装解码组件解决。详细范围见 [DECODERS.md](DECODERS.md)。

## 我的收藏

详情页点击“加入收藏”；右侧“收藏”图标进入收藏页，确认打开最新详情，长按确认或按菜单键可取消收藏。收藏按来源和内容标识区分，最多保留 300 部，保存在本机；覆盖升级保留。来源暂不可用时保留收藏并提示，不存储临时播放链接。当前配置备份不包含收藏和观看历史。

## 界面样式范围

应用自身的提示、确认、列表、简介、线路、选集、收藏管理、设置及地址输入统一使用深色圆角面板；播放菜单使用锚定气泡。系统文件选择器、权限页面，以及第三方网盘/扩展提供的登录界面由各自提供方控制，不属于本应用可统一绘制的页面。

### 海报配色柔光

首页默认提取当前聚焦海报的颜色，让边缘柔光缓慢变化；快速移动时会等待短暂停留再更新，不额外下载背景图片。可在“设置 → 首页与壁纸”关闭。开启“减少动态效果”后颜色直接切换，不播放过渡动画；启用自定义壁纸时优先使用壁纸。


## 开屏动画

冷启动显示约 3 秒原生品牌动画，使用高清原 Logo 和直接绘制的文字，静音，结束后淡入首页。首页同时加载；按遥控器确认、返回或点击画面可跳过。从后台回到应用不重播。可在“设置 → 首页与壁纸 → 开屏动画”关闭；开启“减少动态效果”也会略过动画。动画最多等待约 4 秒，异常时自动进入首页；不依赖开屏视频解码。


## 默认分类与播放返回

首次进入片库时选中“推荐”，焦点停在推荐按钮；返回片库保留此前类别与卡片位置。没有分类的来源使用推荐内容。播放信息可见时，按返回先同时隐藏片名、进度条和 Dock；再次返回缩为小屏，回到介绍选集页。“下集”位于 Dock 最左侧。开屏图标与文字保持紧凑居中，按电视界面分辨率合成，避免整段低分辨率视频放大。


## 顶部观看记录

左侧“继续播放”显示最近观看的一部，右侧“历史记录”最多展示三张更早的观看卡片，各卡片显示封面、集数与进度，确认先进入介绍选集页，再手动继续播放。“全部历史”进入完整记录列表。数量不足时显示实际记录；尚无历史时不占用空白区域。从片库逐级按上返回历史区域会同时露出顶部 Logo；没有历史时，在片源入口继续按上也可回到顶部。


## 搜索响应与续播

输入停顿后仍会自动搜索全部可用且支持搜索的来源。计算拼音与学习标题在后台完成；输入新关键词时暂时保留上一轮结果，开始新搜索后替换，旧请求不能覆盖新结果。首批展示 24 条结果，底部“显示更多结果”每次再补充 24 条，或使用来源筛选；“全部”最多显示 120 条。卡片分批追加，已有卡片不会因其他来源返回而重建。

从搜索结果进入详情再返回，五分钟内可恢复已取得的结果、筛选、焦点和位置；这可能是上次搜索的部分结果，点击“立即搜索”可重新获取。更换配置或修改关键词后会重新搜索。

点击首页继续播放、历史卡片或历史列表，先展示封面、简介、原线路、选集和保存的进度；确认详情页“继续播放”才进入全屏。来源若变更了原线路或集数，会提示重新选集。直接选择某集会按新选择从头播放。


## 焦点与按下反馈

海报、历史卡片、分类、搜索键盘、设置、片源选择、账号面板和播放器按钮采用统一焦点过渡。聚焦约 160 ms，失焦约 140 ms；海报轻微放大，按钮保持位置稳定，背景与描边渐变。按确认或触摸时轻压，松开恢复；快速方向输入会中断旧动画并转向当前焦点，页面退出时释放动画。侧边名称气泡轻微平移并淡入淡出。开启“减少动态效果”后直接切换焦点状态。


## 首页快捷键与首拼匹配

在首页一秒内连续按三次上键，可回到 Logo 和继续播放所在的最顶部；有历史记录时聚焦最近观看卡片，否则聚焦“推荐”。长按上键不会触发三击。按其他键或进入其他页面会重置计数。菜单键直接打开片源选择面板，返回可关闭；搜索、详情和播放页保留各自原有按键逻辑。

首拼与全拼结合本机片名匹配词库、通用字词典和已学习标题。比如首次输入 dldl 或 douluodalu，会按“斗罗大陆”搜索；原始关键词保留为回退请求。词库只是用于匹配的名称文字，不含片库、内容标识、封面、播放地址或来源映射。缩写存在歧义，词库也不可能覆盖所有陌生片名；未知片名可先输入中文搜索，应用会学习该标题，供后续拼音匹配。是否返回内容仍取决于用户配置实际提供的内容与接口状态。


## 搜索来源筛选按钮

搜索结果上方用圆角胶囊按钮区分来源与影片标题。普通按钮为深蓝灰底；已选来源保持蓝灰高亮和加粗文字；遥控器聚焦时变为白底深色文字并轻微放大，确认后才切换筛选。仅移动焦点不会改变当前筛选，焦点移到后面的来源会自动横向滚动显示。


## 遥控移动与流畅度

首页移动会用轻微缩放、边框和按压反馈提示当前焦点。连续上下移动时，列表会从当前位置平滑跟随新目标；加载更多保留已有海报并逐批追加。海报柔光保留，改为小尺寸色场过渡。可在设置开启“减少动态效果”，关闭过渡并直接切换位置。实际流畅度仍受电视性能、配置扩展、海报大小及网络影响。


## 详情加载与连续移动（0.4.9）

进入详情后，海报和片名先显示；获取选集时仍可返回。近期打开过的详情在内存中保留最多 5 分钟，再次进入可复用；退出应用、切换配置或进行账号交互后可能重新加载。缓存不会替代播放时的地址解析。首次打开仍受用户配置接口和扩展自身处理速度影响。

连续方向键移动时，焦点与纵向滚动保留当前速度，快速反向可自然衔接；首页三击上键仍回到最顶部。开启“减少动态效果”会直接切换位置和焦点状态。


## 手机扫码配置与直播快捷键（0.4.11）

在首页导入配置、片源面板的更新配置或设置中的导入入口打开二维码。手机与电视连接同一局域网后扫码，在手机粘贴自行获取的配置地址并提交；电视导入成功后返回首页。二维码有效五分钟，关闭弹窗后失效。仍可选“遥控输入”，再使用电视键盘或本地文件。

直播工具条隐藏时，上键切上一频道、下键切下一频道；频道加/减键按频道序号前进/后退。支持跨分组和首尾循环。数字键按当前直播列表的顺序从 1 编号；连续输入后等待约 1.2 秒跳转，或按确认立即跳转。输入号码时按返回取消。工具条显示时上下键操作工具条；菜单键打开工具条，返回先收起工具条，再返回频道列表。工具条提供“下台”“频道”“线路”，更多面板提供直播专用选项。


## 镜像与应用内更新

[镜像下载页](https://marcotv.wlj9919.top/movie/)提供与 GitHub 同版本、同校验值的安装包及对应源码。镜像任务每 15 分钟计划检查一次已发布预览版，调度与部署可能延迟，并非即时同步。

0.4.12 起，打开设置 → 软件更新，选择检查、下载、安装。默认自动检查并提醒；可选择自动下载或仅手动。自动检查只在首页前台触发，至少间隔六小时，安装仍需本人确认。下载失败可重试；保留的进度支持续传，主动取消则丢弃未完成文件。镜像不可用时尝试 GitHub。

首次安装更新可能需要在系统页面允许本应用安装软件，授权后返回更新页再次选择安装。部分电视不提供系统安装入口，可改用 U 盘或电脑覆盖安装同签名包。安装取消不影响当前版本；不要卸载旧版以免丢失本地数据。

## 屏幕大小与观看距离

应用按分辨率统一界面比例，不以电视标称英寸决定字号。若观看距离较远，在设置 → 首页与壁纸 → 界面大小选择 110% 或 120%。按钮、文字、图标会一起放大，选择后重新载入首页；海报列数可单独调整。厂商缩放、系统字号与特殊屏幕比例仍可能影响显示，反馈时请提供型号、分辨率和照片。

## 扫码提交失败

旧版若手机能打开配置页却提交失败，请先覆盖升级至 0.4.12，再关闭旧页面、重新打开电视二维码并扫描。二维码仅在入口打开且未超时时有效。若仍失败，请记录手机显示的错误文字；配置本身无法访问或无法解析也会提交失败，原配置不会被替换。


## 0.4.13 搜索状态与遥控操作

来源搜索失败、超时或返回空结果时，仍会显示在搜索页上方的来源按钮中。选中后可查看具体状态，并点击“重新搜索此源”；其他来源的结果会保留。空结果不等于该来源没有内容，接口可用性与关键词也会影响返回结果。目录型搜索结果可以继续打开浏览。

点播播放时，工具条隐藏状态下按上或下会同时显示标题、进度与 Dock，焦点落在最左边的“下集”按钮。再按上可进入进度条；返回先收起工具条。直播上下键仍用于换台。

界面按实际可用窗口校准比例。首页列数设置表示每行最多显示的数量；放大界面或缩小可用宽度时会自动减少列数。搜索结果也会调整列数，键盘区域可随焦点滚动。物理英寸与观看距离不能可靠自动获取，较远距离仍可手动选择 110% 或 120%。


## 0.4.14 选集与播放加载

从首页片源切换入口按上进入最近一条“继续播放”，并回到顶部。详情页保留左侧海报，右侧依次显示简介、播放/收藏、平铺线路按钮和选集。聚焦某集时，选集上方显示完整标题。点击线路直接切换，无须打开线路选择弹窗。

来源播放信息与网页解析期间，当前页显示转圈提示；按返回可取消，保留原页面与焦点。来源失败时提示重试，取消后迟到结果不能自行打开播放器。直连媒体直接进入播放器。磁力文件发现仍使用文件选择流程。


## 0.4.15 固定海报与选集排序

详情页左侧海报与顶部返回固定，右侧简介、线路和选集独立滚动。集数旁的“正序 / 倒序”按钮切换展示顺序，并记住选择；分页和全部选集使用同一顺序。已聚焦过某集时，切换排序后定位同一集所在的分组；未聚焦某集时从新顺序的第一组开始。排序保留原始剧集身份与播放顺序，不改变来源定义的下一集关系。


## 0.4.16 手机/平板专属触控界面与跨平台支持

在 Android 手机与平板等触控设备上，应用会自动识别设备形态并进入独立的移动端界面（`MobileShell` 与 `MobileDetailScreen`），不再沿用电视遥控器布局：

- **底部五栏导航与状态栏保留**：手机端底部固定显示 `首页`、`搜索`、`直播`、`我的`、`设置` 五个矢量图标导航栏（平板横屏时自动切换为左侧导航栏）；浏览页面时保留手机系统状态栏与底部手势导航条，且点击卡片不再残留电视遥控器的白色聚焦框。
- **剪贴板一键粘贴与原生输入**：首页欢迎卡片与设置页均支持直接从手机剪贴板一键读取配置网址或 JSON 文本，网址输入框直接调起手机系统输入法并支持长按粘贴，不再弹出二维码扫码页面或电视虚拟键盘。
- **系统输入法搜索与双栏直播**：搜索页直接使用手机自带输入法键盘，支持历史搜索词气泡与多源并发检索；直播页采用左分组、右频道的双栏列表，点选频道即刻播放。
- **移动端详情页与 50 集分组**：详情页上方展示封面、年份/地区/类型与主播放按钮，简介默认折叠为 3 行（点击可展开/收起）；下方提供横向滑动线路胶囊、每 50 集自动分组标签（`1-50`、`51-100`）、正序/倒序切换与 3 列触控选集网格。
- **全屏横屏播放与触控手势**：点选剧集开始播放时自动隐藏系统状态栏并切换为全屏横屏；播放画面支持**单击显示/隐藏控制栏、双击暂停/继续、左右滑动快进快退预览、左半屏上下滑动调节亮度、右半屏上下滑动调节音量、长按 2 倍速快进**；按返回退出播放时自动恢复竖屏与状态栏。
- **Windows / macOS / iOS 跨平台工程**：仓库 `flutter/` 目录提供跨平台客户端工程与云端自动构建，桌面端采用左侧导航栏 + 多列网格，iPhone 端采用底部导航栏 + 3 列网格，支持导入导出与 Android 端互通的 `marco-movie-backup` 备份文件。
