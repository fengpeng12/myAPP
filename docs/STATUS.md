# 功能与验证范围

当前版本：0.4.35。正式版不等于全设备、全配置无条件兼容。

## 当前能力矩阵

| 模块 | 当前支持范围 | 已知边界与限制 |
|---|---|---|
| 配置导入 | 电视端支持局域网手机扫码/网页表单推送、遥控器 HTTP(S) 地址输入；手机/平板端支持剪贴板一键粘贴、系统输入法直接输入、本地 JSON 文件导入；全端支持设置与配置备份还原 | 不内置、不提供、不托管任何配置地址或影视资源；本地文件操作依赖系统文件选择器 |
| 点播来源 | 标准 JSON CMS（`type=1`）、实验性普通 `csp_` JAR 插件（`type=3`，需手动开启）、QuickJS 脚本源 | 混淆/加壳或强绑定特定宿主私有实现的第三方插件不保证兼容 |
| 全局搜索 | 电视端内置全拼/首拼词库与已浏览标题学习；手机/平板端直接调起系统输入法软键盘；多源并发有界调度、单源超时隔离与重试、目录型结果继续展开 | 拼音词库为有限静态词表 + 本地学习，不保证所有生僻缩写均可反查 |
| 播放器与解码 | Media3（含 FFmpeg 音频、dav1d AV1、libvpx VP9 软解扩展）与系统播放器切换、SurfaceView/TextureView 切换、遥控长按加速快进快退、手机全屏横屏触控手势（双击暂停、左右滑快进、左半屏亮度、右半屏音量、长按 2 倍速）、小窗选集、片头片尾跳过、倍速、音轨/外挂字幕、XML/JSON 弹幕 | 4K/HDR 表现取决于设备硬件解码器；合成样本验证不代表所有真实片源或功放透传场景 |
| 直播与磁力 | M3U / TXT 直播源解析、频道分组、电视上下台/数字键选台、手机左右双栏触控选台、失败自动切源；`magnet:?` 顺序分片校验流式播放 | 磁力播放需 Android 8.0+（API 26+）且受限于种子连接数与本机可用缓存空间 |
| 应用内更新 | 镜像与 GitHub 双源版本检查、断点续传、SHA-256 摘要校验、包名/版本递增/同签名证书校验、用户确认后调用系统安装器 | 仅对同签名更新包放行；不静默后台安装 |
| 多端专属界面与跨平台 | Android 端同一 APK 自动区分电视端（遥控器横屏界面）与手机/平板端（`MobileShell` 底部 5 栏导航 / 平板侧边导航、`MobileDetailScreen` 触控选集）；`flutter/` 跨平台工程支持 Windows、macOS、iPhone 与 iPad，并与安卓端互通 `marco-movie-backup` 备份 | Flutter 端支持标准 JSON CMS 点播源与 M3U/TXT 直播源，不支持 Android 专属 `.jar` 插件 |

## 0.4.16 验证范围

1. **纯 JVM 离线回归测试（173 项断言全部通过）**：
   - `run_checks.py`（13 项）：CMS JSON/XML 解析、分页、分类、多线路与特殊字符处理。
   - `run_live_checks.py`（19 项）：M3U / TXT / TVBox 直播分组、请求头继承、重定向与空列表防呆。
   - `run_seek_checks.py`（20 项）：电视遥控长按快进加速曲线、触屏防抖阈值、水平滑动快进映射、左半屏亮度与右半屏音量垂直手势映射。
   - `run_review_fix_checks.py`（43 项）：`SingleFlight` 并发合并、选集正倒序分页定位、`ImageDecodePolicy` 海报采样与内存缓存预算、`Prefs` 28 项白名单与范围守卫、`AppLog` 环形诊断日志、`TvLayoutPolicy` 电视/平板/手机三形态密度与响应式列数。
   - `run_update_checks.py`（51 项）：更新策略、断点续传、证书签名校验与窗口密度计算。
   - `run_tv_input_checks.py`（27 项）：局域网扫码配对服务同源安全校验与直播数字键选台。
2. **多平台云端构建验证**：
   - GitHub Actions `Build Multiplatform` 工作流通过公开内容合规守卫、Windows x64 Release、macOS Release 与 iOS/iPadOS Release 构建及 `flutter test` 单元测试。
3. **电视端基线延续（0.4.15）**：
   - 同一 Android 9 电视通过 139 项定向检查：详情与排序 25、播放器交互 75、搜索与续播 39。

## 仍在完善

全部网盘授权流程、任意扩展或直播列表、长时间播放、所有解码器、DRM 授权样本和磁力视频的电视端表现均未完成穷尽验证。配置导入成功不等于可用；第三方服务还可能随时变更。

持久媒体缓存、渲染视图切换等尚未完成。某些文件操作依赖电视的系统文件选择器。不会把未实现功能作为已有能力展示。
